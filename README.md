# 📊 HabitPulse | Interactive Habit & Streak Tracker Dashboard

An interactive, dark-themed personal habit tracking dashboard built with a sports-tech aesthetic. Designed to track daily goals, monitor weekly streaks, and visualize execution consistency in real time.

🔗 **Live Demo:** [https://kenlin3002-source.github.io/test/](https://kenlin3002-source.github.io/test/)

---

## ✨ Key Features

- **Real-Time KPI Metrics**: Automatically calculates daily completion percentage, weekly overall execution rate, best weekly streak, and 100% perfect days.
- **Daily Focus Checklist**: Quick-toggle daily tasks categorized by domain (Workout, Study, Lifestyle, Creative) with animated progress feedback.
- **Weekly Streak Matrix**: A Monday-to-Sunday interactive grid allowing instant status toggling across any day of the week.
- **Dynamic Data Visualization**:
  - **Daily Completion Trend (Bar Chart)**: Tracks execution consistency across the week.
  - **Streak vs. Weekly Total (Horizontal Bar Chart)**: Compares current active streaks against cumulative weekly check-ins per habit.
- **Client-Side Persistence**: Powered by the browser's `localStorage` API—custom habits and check-in records are saved automatically without requiring a backend server.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- **Charts**: [Chart.js](https://www.chartjs.org/)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **CI/CD Deployment**: GitHub Actions & GitHub Pages
